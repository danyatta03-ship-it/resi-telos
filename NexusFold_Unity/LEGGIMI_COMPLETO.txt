PASSI OBBLIGATORI (TU)
───────────────────────────────────────────
1. Unity Hub → New Project → URP (2D o 3D)
2. Copia cartella Scripts/ dentro Assets/
3. Crea Assets/Art/UI/ e importa:
   - immagine MENU (portale)
   - immagine NEGOZIO (pacchetti)
   Texture Type = Sprite (2D and UI)
4. Crea scene in Assets/Scenes/:
   Boot, MainMenu, Shop, HeroSelect, Battle
   Aggiungile in Build Settings in quest’ordine
5. Scena Boot:
   - GameObject vuoto + BootLoader.cs
   - GameObject vuoto + GameManager.cs
6. Scena MainMenu:
   - Canvas (Scale With Screen Size 1080×1920)
   - Image/RawImage sfondo = tua foto Menu (stretch)
   - 5 Button con Image alpha=0 posizionati su:
     GIOCA → MainMenuUI.OnClickGioca
     Collezione → OnClickCollezione
     Negozio → OnClickNegozio
     Clan → OnClickClan
     Profilo → OnClickProfilo
   - Aggiungi MainMenuUI.cs al Canvas
7. Scena Shop:
   - Stesso metodo con immagine Negozio
   - Bottoni invisibili sui pacchetti → ShopUI.BuyBasic / BuyRare / ...
   - Bottone Indietro → OnClickBack
8. Premi Play sulla scena Boot

DOPO CHE MENU E SHOP FUNZIONANO
───────────────────────────────────────────
HeroSelect:
  - Grid di bottoni eroe
  - 8 HeroData (Create → NexusFold → Hero Data)
  - Compila da CARDS_DATABASE.txt sezione EROI
  - HeroSelectUI + OnClickStartBattle

Battle:
  - Testi HP / Energia / Turno
  - Board 5×5 (Grid Layout + prefab cella con BoardCell)
  - Mano (prefab carta)
  - BattleManager + starterCards (alcuni CardData)
  - Bottoni Fine Turno / Abilità / Esci

Carte:
  - Create → NexusFold → Card Data per ogni riga di CARDS_DATABASE.txt
  - Assegna artwork quando le hai generate

Fusione:
  - Chiama FusionSystem.TryFuse(cardA, cardB, out result)
  - Usa in Battle o in schermata dedicata
